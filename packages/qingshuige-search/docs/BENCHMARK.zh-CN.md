# 性能基准

本项目提供一个轻量的 Node.js 基准脚本，用于测量 JSON 解析、索引构建、近似堆内存增量和热查询平均延迟。

## 使用方法

```bash
npm run benchmark -- /path/to/search-index.json Hugo 计算机 GitHub
```

建议使用由实际静态站点生成的 `search-index.json`，这样结果最接近真实使用场景。

## 清水阁当前基线

测试日期：2026-09-07  
Node.js：22.16.0  
文档数量：163  
JSON 原始大小：443,161 bytes

一次代表性测试结果：

- JSON 解析：约 0.33 ms
- 索引构建：约 141–145 ms
- 索引构建后的近似堆内存增量：约 17.7 MB
- 常见热查询：约 0.02–0.15 ms
- 作者或年份这类结果较多的查询：约 0.36–0.58 ms
- JSON gzip：约 197–199 KB
- JSON Brotli：约 160–180 KB，取决于压缩等级

这些结果表明，当前 163 篇文章的查询阶段开销很低，主要成本集中在第一次打开搜索时的索引构建和内存占用。后续优化应优先关注索引体积、`positions` 存储和首次构建，而不是微优化单次查询。

## 注意

该脚本测试的是核心搜索引擎，不包含浏览器网络延迟、Vue 初始化、DOM 渲染和 Vite bundle 体积。不同设备和浏览器结果会明显不同，因此正式发布前还应在桌面端和移动端浏览器分别测试。
